# GPT Mobile 0.9.0-2

基于上游 0.9.0，增强 OpenAI 与兼容接口的模型管理、会话控制和用量展示，并完善简体中文体验。

## 安装信息

- 显示版本：`0.9.0-2`
- 内部版本号：`27`，高于此前本地测试包的 `26`
- 最低系统：Android 12 / API 31
- 包名：`dev.chungjungsoo.gptmobile`
- 构建：经过压缩优化、关闭调试标志的 Release APK
- 签名：沿用本分支此前本地安装包的开发签名证书，支持同签名升级；不是上游商店签名

## 提供商模型目录

- 根据 API 基础地址和密钥获取 `models` 列表，使用下拉选择模型。
- 目录随提供商持久化保存，切换与重启无需重新拉取。
- 手动刷新成功替换旧目录，失败保留旧目录，合法空列表可清空旧目录。
- 不同提供商的目录相互独立；更改连接地址、密钥或协议后清空旧缓存。
- 保存旁增加连接检测，使用短模型请求验证配置。

## 会话控制与 Fast

- 在输入框上方切换提供商、模型和推理强度，保留历史回复。
- 模型切换使用直接下拉列表，与推理选择交互一致。
- 推理档位为 `low / medium / high / xhigh / max`；关闭深度推理或选择“默认”时不发送强度参数。
- OpenAI 模型列表顶部新增默认关闭的 Fast 选项，勾选后发送 `service_tier: "priority"`。
- Fast 按会话中的提供商保存，不会自动加入其他类型提供商的请求。
- 重开会话时优先显示有内容的回复列，避免切换提供商后出现空白占位。

## 回复信息、布局与中文

- 用户消息显示发送时间；模型回复显示答复时间、执行耗时和 token 总量。
- 信息单行简写，例如 `14:36 · 5s · 172k`；点击时间查看完整日期，点击 token 查看输入、输出和缓存明细。
- 回复底部压缩为两行操作信息和一行必要提示，版本切换并入操作栏，单版本时隐藏冗余控件。
- 上下文用量环显示已用、剩余和窗口容量，缺失数据保持未知。
- 补齐 298 条简体中文文案及复数资源，统一设置、工具、上下文和错误提示的表达。

## 发布前修复

- 修复上下文摘要位于消息首部时，Fast 无法识别实际会话的问题。
- 修复带首尾空格的密钥在服务端错误说明中可能未完整脱敏的问题。
- 避免修改其他提供商设置时覆盖已刷新的模型目录。

## 升级须知

- 无需卸载同签名旧版，数据库自动迁移并保留记录。
- 旧版没有保存过模型目录，升级后请先手动刷新一次。
- 旧回复及未回传用量不会补算。缓存输入包含在输入 token 中，不能重复加到总量上。
- 上下文环表示最近一次请求的占用，不是累计费用，也不包含草稿。
- 连接检测可能消耗少量 token；Fast 的可用性、处理速度和价格取决于提供商。

- 停止模拟服务并重启应用后，模型列表仍可从本地加载。
