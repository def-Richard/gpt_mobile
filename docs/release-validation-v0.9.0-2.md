## Release 安装包检查

在 Android 15（API 35）模拟器中，使用签名后的 Release APK 进行覆盖安装与冷启动检查：

- 安装成功，包名与版本号正确，系统包标志不含 DEBUGGABLE。
- 原有会话仍可打开，历史回复与紧凑信息栏正常显示。
- 模型目录可通过模拟接口刷新并选择。
- 停止模拟服务、强制结束应用并重新启动后，模型菜单仍从本地显示已保存的完整目录。

这些检查不等同于对所有真实模型、MCP 服务或端侧推理硬件的完整认证。
