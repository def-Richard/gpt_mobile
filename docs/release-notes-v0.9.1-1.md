# GPT Mobile 0.9.1-1

同步上游 v0.9.1，并修复 OpenAI Responses 兼容网关中“能选择图片，发送后报 JSON 解析错误”的问题。

## 更新内容

- 合并上游至 `b79433c`，包含流式请求异常与取消处理、LiteRT 发布修复和翻译更新。
- 新图片直接以 Base64 随 Responses 请求发送，不再要求网关实现 Files API。
- 已有可用图片文件引用继续复用，失效引用自动改为直接发送，保留其他提供商的引用。
- OpenAI 直接发送的附件总量限制为处理后 12 MiB，超限会提示减少图片或新建会话；上下文压缩请求也执行此检查。
- 保留本分支的模型目录、会话内模型切换、Fast、用量展示和简体中文功能。

## 安装与升级

- 版本 `0.9.1-1`，内部版本号 `28`；最低 Android 12 / API 31。
- 包名 `dev.chungjungsoo.gptmobile`，包含 `arm64-v8a` 等架构。
- Release 构建已压缩优化，关闭调试标志；沿用本分支此前的开发签名证书，支持同签名覆盖升级并保留数据。
- 签名不是上游商店签名，其他渠道安装包不保证能直接覆盖。
- 本次发布的 APK 与 S23 Ultra 上验证成功的安装包完全相同。

## 验证

- 738 项单元测试通过；ktlint 通过；Android lint 为 0 错误、125 条警告。
- 回归测试复现旧版 Files API 返回 HTML 的错误，并验证修复后的 Responses 图片请求。
- 三星 Galaxy S23 Ultra 已完成保留数据升级，原失败图片重试成功。
- APK 签名与 ZIP 对齐检查通过。

附件提供 `SHA256SUMS.txt` 用于核对下载文件。详见[验证记录](release-validation-v0.9.1-1.md)。
